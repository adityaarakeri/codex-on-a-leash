# Security Policy

## Scope

`codex-on-a-leash` is a guardrail project. It reduces common risky behaviors in Codex, but it is not a complete sandbox or a guarantee against determined abuse.

## Reporting a vulnerability

If you believe you found a security issue in this project, please open a private security advisory on GitHub or contact the maintainer privately before opening a public issue.

When reporting, include:

- affected version
- reproduction steps
- expected behavior
- observed behavior
- potential impact

## Safe disclosure

Please avoid publishing weaponized proof-of-concept details until a fix is available.
